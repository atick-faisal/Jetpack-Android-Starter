JetpackEntity

data class JetpackEntity(val id: String = UUID.randomUUID().toString(), val name: String, val price: Double, val userId: String = String(), val lastUpdated: Long = 0, val lastSynced: Long = 0, val serverUpdatedAtNanos: Long = 0, val needsSync: Boolean = false, val deleted: Boolean = false, val syncAction: SyncAction = SyncAction.NONE)(source)

Room row containing Home content and local sync metadata.

The repository sets pending metadata on local writes; entity construction alone does not schedule work. Pulled rows carry remote content/timestamps and default to no pending action. Acknowledgement clears pending flags by ID, without a version check. Deleted rows remain locally after remote acknowledgement; no automatic cleanup is implemented.
