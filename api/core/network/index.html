Gotchas

  • Each collection seeds from the active network’s NET_CAPABILITY_INTERNET, then registers a default-network callback and collapses consecutive duplicates. Availability reports CONNECTED; capability changes are only logged. This does not check NET_CAPABILITY_VALIDATED or guarantee reachable Internet access, and the snapshot/registration sequence is not atomic.

  • NetworkState.LOSING is declared but never emitted; the callback logs it without sending a state.

  • The app uses this module’s connectivity monitor and shared image-loader configuration even though Home uses Firestore. REST integration is an optional extension; see the data guide.

  • The base URL is a build secret, not a constant: the Gradle Secrets plugin reads BACKEND_URL from secrets.defaults.properties (version-controlled default) or local.properties (real value, gitignored) into BuildConfig.BACKEND_URL, consumed by RetrofitModule.
