NavigationState

class NavigationState(val startKey: NavKey, val topLevelStack: NavBackStack<NavKey>, val subStacks: Map<NavKey, NavBackStack<NavKey>>)(source)

Holds the app's navigation state. This class never modifies itself — all changes go through Navigator, which keeps "what the state is" separate from "what a navigation event does".
