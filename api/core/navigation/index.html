:core:navigation

Purpose: Jetpack Navigation 3 multi-back-stack state and a Navigator for changing it. Destination keys implement NavKey; screens register entries in the app’s entry provider.

// core/navigation/src/main/kotlin/dev/atick/core/navigation/Navigator.kt
fun navigate(key: NavKey) {
    when (key) {
        state.currentTopLevelKey -> clearSubStack()
        in state.topLevelKeys -> goToTopLevel(key)
        else -> goToKey(key)
    }
}

Gotchas

  • Navigator deduplicates equal keys within the current sub-stack, not across tabs. Different arguments of the same data-class key can identify different destinations.

  • In the pinned Navigation 3 version, NavEntry.contentKey defaults to key.toString(). Duplicate content keys in flattened stacks can collide in saved state and ViewModel ownership; sharing a key type alone is not a collision. See entry identity.
