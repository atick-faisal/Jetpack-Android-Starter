FakeAuthDataSource

class FakeAuthDataSource(initialUser: AuthUser? = null) : AuthDataSource(source)

In-memory AuthDataSource for tests, so repository tests do not need Firebase.

The signInWith* methods take an Activity, which a unit test has no way to produce. They are left unimplemented on purpose: a test that reaches one is testing something that belongs in an instrumented test, and failing loudly says so.
