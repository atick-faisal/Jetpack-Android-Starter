FirebaseDataSource

interface FirebaseDataSource(source)

Firestore operations under /dev.atick.jetpack/{userId}/jetpacks/{documentId}.

The repository owns Room persistence, pending metadata, and push/pull ordering. These calls propagate SDK failures; they do not resolve conflicts or acknowledge local rows.
