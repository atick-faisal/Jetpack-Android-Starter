:app

Purpose: The application module — composes feature screens and supplies application-level wiring behind MainActivity and JetpackApp, and owns app-level config (signing, versioning, ProGuard).

Gotchas

Important: MainActivity extends AppCompatActivity, not ComponentActivity, to support setApplicationLocales for backward-compatible per-app language selection — the manifest sets android:theme="@style/Theme.AppCompat" to prevent a crash from that combination.

  • Theme resolution combines isSystemInDarkTheme() with DarkThemeConfigPreferences (FOLLOW_SYSTEM/LIGHT/DARK) collected via repeatOnLifecycle(STARTED).

  • A release build without keystore.properties falls back to the debug signing key — see Getting Started for the full trap.
